Decimal vs binary data units

Data units come in two families, and mixing them up is the most common source of confusion.

  • Decimal (SI) units use powers of 1,000: 1 KB = 1,000 bytes, 1 MB = 1,000,000 bytes, 1 GB = 109 bytes. Storage makers, network speeds and macOS use these.
  • Binary (IEC) units use powers of 1,024: 1 KiB = 1,024 bytes, 1 MiB = 1,048,576 bytes, 1 GiB = 1,073,741,824 bytes. Windows uses these but labels them "KB, MB, GB", which is why a new drive looks smaller than advertised.

Bits and bytes: 1 byte = 8 bits. Internet speeds are quoted in bits per second (Mbps, lowercase b). File sizes are in bytes (MB, uppercase B), so divide Mbps by 8 to get MB/s.

Frequently asked questions

How many MB are in a GB?

In decimal units, 1 GB = 1,000 MB. In binary units, 1 GiB = 1,024 MiB. Storage makers use the decimal definition; Windows uses the binary one but labels it GB.

Why does my 1 TB drive show 931 GB?

The drive holds 1,000,000,000,000 bytes. Windows divides by 1,024³ and shows 931 "GB" (really 931 GiB). No space is missing; it is a different unit.

How do I convert Mbps to MB/s?

Divide megabits per second by 8. A 100 Mbps connection transfers at most 12.5 MB/s, so a 1 GB file takes about 80 seconds.

What is the difference between a bit and a byte?

A bit is a single 0 or 1. A byte is 8 bits. Speeds use lowercase b (Mbps, bits); file sizes use uppercase B (MB, bytes).

What is the difference between KB and KiB?

1 KB (kilobyte) is 1,000 bytes. 1 KiB (kibibyte) is 1,024 bytes. The gap grows with size: 1 TiB is about 10% larger than 1 TB.
